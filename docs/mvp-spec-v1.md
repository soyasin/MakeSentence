# MakeSentence MVP 1차 명세

## 1. 목표
영어 문장을 조합해 짧은 스토리를 만들고, 피드백을 통해 영어 학습 효과를 얻는 최소 기능 제품(MVP)을 구현한다.

## 2. 핵심 사용자 시나리오
1. 사용자가 로그인(또는 게스트 시작)한다.
2. 제시된 단어 카드/패턴으로 영어 문장을 1개 작성한다.
3. 문장을 여러 개 이어 3~5문장 스토리를 완성한다.
4. 앱이 문장 정확도/표현 추천 피드백을 제공한다.
5. 스토리를 저장하고 복습 화면에서 다시 학습한다.

## 3. MVP 범위 (Must)
### 3.1 문장 만들기 게임
- 단어 카드 드래그/탭 조합
- 기본 문장 패턴 가이드(S+V+O 등)
- 문장 검증(기초 문법 규칙 + 허용 패턴)

### 3.2 스토리 빌더
- 3~5문장 묶음으로 1개 스토리 생성
- 문장 순서 변경, 삭제, 수정

### 3.3 학습 피드백
- 맞춤법/기초 문법 체크
- 더 자연스러운 표현 1~2개 추천
- 문장별 점수 + 전체 스토리 점수

### 3.4 저장/복습
- 스토리 저장
- 내 스토리 목록/상세 보기
- 틀린 표현 다시 보기

### 3.5 기본 계정
- 게스트 또는 간편 로그인(구글/애플 중 1개)

## 4. 제외 범위 (MVP 이후)
- 실시간 멀티플레이
- 음성 인식/발음 채점
- 고급 AI 튜터 대화
- 소셜 피드/공유 기능

## 5. 화면 구성 (MVP)
1. 온보딩/로그인
2. 홈(학습 시작, 최근 스토리, 진행도)
3. 문장 만들기 화면
4. 스토리 편집 화면
5. 결과/피드백 화면
6. 내 스토리 목록
7. 스토리 상세/복습 화면
8. 설정(언어레벨, 알림)

## 7. 채점/피드백 규칙 (MVP 단순 버전)
- 점수 100점 시작
- 오탈자: -5
- 기본 어순 오류(SVO 위반 등): -10
- 시제 불일치(기초 룰): -10
- 문장 길이/완성도 보너스: +0~10
- 추천 표현은 룰 기반 템플릿 우선(LLM 의존 최소화)

## 8. 비기능 요구사항
- 평균 화면 전환 < 1.5초
- 문장 검증 응답 < 800ms(로컬 룰 기준)
- 크래시 프리 세션 99%+
- 저장 데이터 무결성(스토리/문장 원자적 저장)

## 9. 기술 제안 (MVP 현실안)
- 클라이언트: Flutter (iOS/Android 동시 대응)
- 백엔드: Firebase (Auth, Firestore, Cloud Functions)
- 검증 엔진:
  - 1차: 로컬 규칙 + 서버 보조 검증
  - 2차: AI 교정 확장 가능 구조

## 10. API/함수 스펙 (초안)
- `POST /stories` 스토리 생성
- `POST /stories/{id}/sentences` 문장 추가
- `PATCH /sentences/{id}` 문장 수정
- `POST /evaluate/story/{id}` 스토리 평가
- `GET /stories?userId=...` 목록 조회
- `GET /progress/{userId}` 학습 통계

## 11. 수용 기준 (Acceptance Criteria)
- 사용자는 3문장 이상 스토리를 작성/저장할 수 있다.
- 각 문장에 대해 점수와 최소 1개 피드백이 표시된다.
- 저장한 스토리를 목록에서 열어 복습할 수 있다.
- 로그인 사용자는 재접속 시 데이터가 유지된다.
